# iankitkumar.in

Gamified portfolio for [iankitkumar.in](https://iankitkumar.in).

## Stack

Static HTML / CSS / JS on Cloudflare Pages.

## Local

Open `index.html` or serve the folder:

```bash
python3 -m http.server 5173
```

## Deploy

```bash
wrangler pages deploy . --project-name=iankitkumar-in
```
